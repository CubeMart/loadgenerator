# CubeMart Load Generator

![CubeMart](https://img.shields.io/badge/CubeMart-Load%20Generator-0f766e)
![Python](https://img.shields.io/badge/Python-Service-3776AB)
![Locust](https://img.shields.io/badge/Locust-Performance%20Testing-1f2937)

Traffic generation service used to simulate user activity across CubeMart workflows for testing and demo environments.

## Responsibilities

- Generate storefront traffic
- Simulate add-to-cart and checkout activity
- Help validate platform behavior under load
- Support performance and reliability testing
